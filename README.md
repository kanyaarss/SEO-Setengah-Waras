## What This Repo Is

This repository is a **technical notebook** about SEO from an attacker and system-engineering perspective.

It contains:
- backlink structures and tier logic
- AMP & cache behavior observations
- blackhat SEO techniques (past & present)
- psychological and behavioral manipulation notes
- case studies from real experiments

This is **not** a step-by-step tutorial.
This is **not** beginner-friendly.
And this is definitely **not whitehat SEO propaganda**.
